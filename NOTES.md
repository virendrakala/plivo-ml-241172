Our best configuration achieves a dev Bits-Per-Byte (BPB) of 1.9307 (down from the 2.3718 baseline). The most impactful change was training a custom Byte-Pair Encoding (BPE) tokenizer with 512 merges (vocab size 768) directly on the provided corpus, which compressed the Devanagari script from 3 bytes per character down to 1-2 tokens, effectively expanding the model's context window by 2.6x. We maximized the 2,000,000 parameter budget by using weight tying (saving ~150k parameters) to afford a wider model: 4 layers, 192 embedding dimension, 8 attention heads, and a block size of 256 (totaling 1,976,448 parameters). We initialized the model with GPT-2 style scaled residuals (std=0.02 / sqrt(2*n_layer)) to stabilize early training. For optimization within the strict 2,000 step limit, we replaced the constant LR Adam optimizer with AdamW (weight decay 0.1) and applied a cosine learning rate schedule (peak LR 1e-3, min 1e-4) with a 100-step linear warmup. We also introduced gradient clipping (norm 1.0) and gradient accumulation (effective batch size 64) to drastically smooth the loss curve and improve final convergence.
